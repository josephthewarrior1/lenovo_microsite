# Local project

The user wants this website developed and previewed locally in this folder. Do not publish, deploy, push to a remote repository, or invoke Sites hosting unless the user explicitly requests it in a later message. Preserve the existing local website and assets.

The website files are in `dist/`. Run `python -m http.server 4173 --bind 127.0.0.1 --directory dist` from this directory for a local preview.
